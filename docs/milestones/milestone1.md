# Milestone 1 — Skeleton

Produce a runnable application with no intelligence.

## Success criteria:

* Go backend
* Vite frontend
* Single binary
* Embedded frontend
* Configuration
* Logging
* OpenAI-compatible chat . endpoint abstraction (even if only one provider initially)
* Task repository on disk
* Project repository on disk
* Basic API

## Out of scope
* No workflow.
* No routing.
* No policy.

Just architecture.
